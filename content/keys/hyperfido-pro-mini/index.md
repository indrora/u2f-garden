The HyperFIDO Pro Mini is one of five HyperFIDO Pro variants. It is a USB-A only nub style key, designed for users who keep a key in a port full time and do not need to carry it. HyperSecu's product page consolidates branding under "HyperFIDO Pro" with variant suffixes (Mini, Titanium, USB-C, Bio, NFC). The other four are:

* [HyperFIDO Pro Titanium](../hyperfido-pro-ti/) for a larger USB-A keychain form.
* [HyperFIDO Pro USB-C](../hyperfido-pro-usbc/) for USB-C systems.
* [HyperFIDO Pro Bio](../hyperfido-pro-bio/) for fingerprint authentication.
* [HyperFIDO Pro NFC](../hyperfido-pro-nfc/) for tap to authenticate over NFC.

All five share the same base FIDO2 stack with optional HOTP. HyperSecu's keys are produced on a customised Feitian platform, so the underlying secure element is shared with several other vendors in this catalog.

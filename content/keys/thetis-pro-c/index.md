The Thetis PRO-C pairs USB-C with NFC in the standard Thetis folding shell. It supports FIDO2, U2F, discoverable credentials, OATH HOTP and TOTP. For the aluminium shielded variant, see [PRO-C Plus](../thetis-pro-c-plus/). For the triple interface flagship that adds USB-A on the same body, see [PRO FIDO2](../thetis-pro-fido2/).

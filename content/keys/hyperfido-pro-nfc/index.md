The HyperFIDO Pro NFC pairs USB-C with NFC and is the only HyperFIDO Pro variant whose datasheet calls out the underlying secure element rating: Common Criteria EAL 6+. The protocol stack is otherwise the standard HyperFIDO Pro: FIDO2, U2F, discoverable credentials, and optional HOTP.

For the same body without NFC but with a fingerprint sensor instead, see [Pro Bio](../hyperfido-pro-bio/).

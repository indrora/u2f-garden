The EzFinger Desktop is a larger desktop sized fingerprint reader from Octatco. It is meant to live on a desk rather than be carried, and provides FIDO2 plus Windows Hello sign in for users who do not want a portable key.

This is closer to a desktop biometric reader than a portable security key, in the same category as the now discontinued Kensington VeriMark Desktop. Worth considering for fixed workstations where the user logs into a single machine repeatedly.

The Octatco EzFinger2 is a fingerprint capacitive sensor FIDO2 and U2F key in a USB-A form. The newer EzFinger2+ revision adds a faster sensor and updated cryptography. Both run on the same FIDO firmware base, support discoverable credentials, and integrate with Windows Hello.

For the USB-C variant, see [EzFinger C](../octatco-ezfinger-c/). For a desktop sized fingerprint reader variant, see [EzFinger Desktop](../octatco-ezfinger-desktop/). For the variant with an on board quantum random number generator, see [EzQuant](../octatco-ezquant/).

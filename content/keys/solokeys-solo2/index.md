The Solo 2 is the current SoloKeys flagship, sold in USB-A and USB-C variants for around thirty five United States dollars. It is built on the open source Trussed firmware framework and runs on a microcontroller secure boot path that is fully documented in the SoloKeys repositories.

Solo 2 supports FIDO2 with discoverable credentials and U2F. There is no PIV, no OpenPGP, no OATH, and no biometrics. The key is what its name implies: a single purpose FIDO2 device that you can audit end to end.

For NFC tap to authenticate, see [Solo 2+ NFC](../solokeys-solo2-nfc/). A "Hacker" developer variant is also sold for users building or modifying firmware.

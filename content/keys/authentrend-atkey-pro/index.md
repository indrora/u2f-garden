The ATKey.Pro is AuthenTrend's main fingerprint FIDO2 key. It is FIDO2 CTAP 2.1 certified and supports Windows Hello passwordless flows, including Microsoft Entra ID. The base model is offered in USB-A and USB-C. The Zinc edition uses an identical electronics package in a heavier zinc alloy shell, with no functional difference.

User verification is fingerprint first, with PIN fallback. AuthenTrend provides a Windows management application for fingerprint enrolment and key reset.

For a smartcard form factor with NFC, see [ATKey.Card](../authentrend-atkey-card/). The previously sold ATKey.Hello, a smaller fingerprint dongle for Windows Hello with U2F, has been retired.

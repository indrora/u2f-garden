The HyperFIDO Pro Bio adds an on device fingerprint sensor to the HyperFIDO Pro stack. Authentication is gated by fingerprint with PIN fallback. Available only as USB-C.

The biometric variant does not include NFC. If you need NFC tap to authenticate, see [Pro NFC](../hyperfido-pro-nfc/), which has NFC but no fingerprint.

The Idem Key was the first FIDO2 Level 2 certified token on the market. The Level 2 certification requires hardware backed key protection, which is rare in this price range. The current Idem Key family on gotrustid.com is sold as three SKUs:

* The standard Idem Key in USB-A and USB-C variants, both with NFC.
* The [Idem Key Plus](https://gotrustid.com/idem-key-plus/), which adds Web PKI and PKCS#11 middleware paths for organisations that need PIV style smart card behaviour.
* The Idem Key Mini, a compact USB-C plus NFC form factor.

GoTrust advertises an IP68 ingress rating and a crush rating up to 6,150 pounds on the standard Idem Key body. The vendor management software, IdemPass, is a Windows and macOS desktop sign in companion that uses the Idem Key without typed passwords.

The card form sibling, [IdemCard](../gotrust-idemcard/), has had its product page retired. The Idem Key family is the actively marketed product.
